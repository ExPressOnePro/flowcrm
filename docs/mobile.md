# Мобильная версия

Интерфейс один для всех устройств (mobile-first), без отдельного мобильного
приложения и без уменьшения масштаба страницы.

## Брейкпоинты

| Ширина | Навигация | Списки |
|---|---|---|
| < 768 (`md`) | Нижняя панель: Главная, Автопарк, Документы, Путевые листы, Ещё | Карточки |
| 768–1023 | Боковое меню | Карточки реестра ТС в 2 колонки, остальные списки — таблицы |
| ≥ 1024 (`lg`) | Боковое меню | Таблица реестра с сортировкой по колонкам |

Проверяемые ширины: 320, 360, 390, 430, 768, 1024, 1440 — без горизонтальной
прокрутки страницы. Широкие таблицы прокручиваются только внутри своего блока.

## Оболочка

- `components/mobile/bottom-nav.tsx` — нижняя панель; скрывается, пока открыта
  экранная клавиатура (фокус в текстовом поле). «Ещё» открывает лист с разделами,
  отфильтрованными по правам пользователя (`useNavPermissions` в `lib/navigation.ts`),
  и учётной записью.
- `components/app-sidebar-header.tsx` — на телефоне: кнопка «Назад» (история
  внутри приложения, иначе родительская хлебная крошка) и заголовок экрана.
- `components/responsive-sheet.tsx` — нижний лист на телефоне, боковая панель на
  десктопе. Используется для фильтров и быстрых действий (статус, пробег, сцепка)
  и для форм документов. Общие поля и нижняя панель кнопок форм —
  `components/sheet-form.tsx`.
- Колокольчик уведомлений (`components/notification-bell.tsx`) — в шапке на всех
  ширинах, со счётчиком непрочитанных.
- Safe area: `viewport-fit=cover`, утилиты `pt-safe`/`pb-safe`;
  `interactive-widget=resizes-content` — клавиатура не перекрывает поля.

## Касания и формы

- Кнопки и поля на телефоне — не меньше 44 px (`components/ui/button.tsx`,
  `resources/css/app.css`); шрифт в полях 16 px, чтобы iOS не увеличивал страницу.
- Госномер и VIN — без автозамены и с заглавными буквами; числовые поля —
  `inputMode="numeric"`.
- Обязательные поля помечены `*`. Формы создания и редактирования ТС сохраняют
  введённое при переходах (`useForm` с ключом) и предупреждают об уходе с
  несохранёнными изменениями (`hooks/use-unsaved-changes.ts`).
- Опасные действия (списание, архив) подтверждаются через `useConfirm()`
  (`components/confirm-dialog.tsx`).
- Повторная отправка: кнопки блокируются на время запроса, показания одометра
  защищены от дублей на сервере (см. `fleet.md`). Формы документов отправляют
  ключ идемпотентности (`lib/idempotency.ts`).
- Файлы (`components/documents/file-picker.tsx`): две кнопки — «Сфотографировать»
  (`capture="environment"`, открывает камеру на телефоне) и «Выбрать файлы».
  Формат, размер и количество проверяются до отправки; при загрузке виден прогресс.
  Закрытие формы с введёнными данными или выбранными файлами требует подтверждения.

## Загрузка данных

Списки — серверная пагинация. История ТС и журнал изменений подгружаются при
открытии вкладки порциями по 30 (`hooks/use-paged-fetch.ts`), документы ТС — одним
запросом (`hooks/use-json.ts`), с состояниями
загрузки, пустого результата и ошибки с повтором. При потере сети показывается
уведомление.

## PWA

- `public/manifest.webmanifest`, иконки в `public/icons/`, `public/apple-touch-icon.png`.
- `public/sw.js` регистрируется только в production-сборке и в защищённом
  контексте (HTTPS). Кеширует **только** статические файлы сборки
  `/build/assets/*` (имена с хешем). HTML-страницы, API/JSON-ответы и файлы
  пользователей не кешируются; файлы документов отдаются с `Cache-Control: no-store`.
- Офлайн-режима и push-уведомлений нет: для них нужно отдельное проектирование
  синхронизации и оценка безопасности.
- Обновление: при изменении логики SW сменить имя кеша `flowcrm-static-vN`.
